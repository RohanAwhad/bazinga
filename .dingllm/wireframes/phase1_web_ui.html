Artifact API

The Artifact API serves the contents of the .dingllm/ directory over HTTP GET. It supports two endpoints:

  • GET /artifacts — list all artifacts (diagrams, PRDs, constitution files)
  • GET /artifacts/{path} — fetch a single artifact by relative path

Only files with approved extensions (.md, .mmd, .txt) are served. Binary files and dotfiles are excluded.

If the .dingllm/ directory does not exist, the list endpoint returns an empty array rather than an error.
