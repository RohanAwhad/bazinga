# Mission

**Bazinga** is a multi-turn CLI coding agent powered by Gemini 3.1 Pro via Vertex AI.

It accepts text, video, and PDF input and has tool-use capabilities for local file manipulation: listing directories, reading files, and search-and-replace editing.

## What it is

- A terminal-based interactive chat with an LLM
- An LLM agent with file system tools (list, read, edit/create)
- Uses Google Vertex AI (Gemini 3.1 Pro) as the model backend

## What it is NOT

- Not a web application or API server
- Not a framework or library for others to import
- Not a multi-model orchestrator (single model: Gemini 3.1 Pro)
- Not a general-purpose automation platform
